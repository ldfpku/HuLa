# 邮箱、待办与在线状态：人工专项测试清单

## 开始前

- 先确认桌面版本为 **1.4.0**，Web 页面及邮箱服务使用本次配套部署；如果更新未出现，或版本不一致，记录为阻塞，不用旧版本判定。
- 以 A、B 两个授权测试账户分别登录：尽可能使用两台电脑，至少覆盖 Windows 桌面和桌面浏览器；有条件再测真实手机浏览器、macOS 和 Linux。每种设备及方向单独记录，不以浏览器模拟代替真机。
- 只使用自己新建的合成测试邮件、附件、任务和仅含两账户的测试群。测试消息注明操作者身份、测试目的和用例编号；不访问其他人的内容。
- 使用前记录自己的在线状态、通知权限及相关设置；结束后恢复。只清理本轮自己创建的数据，不删除现有资料或修改密码。截图和反馈不要包含密码、验证码、登录链接、令牌、真实邮件或其他人的资料。
- 不要求通过中断共享网络、调整系统全局设置或操纵其他人的通知来制造故障；无法安全隔离的步骤记为阻塞。

## 测试步骤

| 编号 | 重点及步骤 | 预期结果 |
| --- | --- | --- |
| MAN-01 | **版本与启动**：检查桌面“关于/检查更新”版本，启动并登录；浏览器打开 Web 入口，刷新并重新进入。 | 桌面为 1.4.0；两端可以正常登录、显示主界面，刷新或重启后账户正确。 |
| MAN-02 | **邮箱嵌入**：Windows 桌面点击左侧邮箱，打开收件箱和一封合成邮件，再切换聊天、待办并返回邮箱。 | 邮箱在同一个主窗口内，最左导航仍可用；未打开独立邮箱窗口，返回后邮箱内容和聊天状态保留。 |
| MAN-03 | **各邮件入口**：从搜索结果、聊天中的测试邮件卡片、待办来源分别打开有权限的测试邮件。 | 均进入同一邮箱工作区和对应邮件；无权限的邮件有明确提示，不泄露内容。记录无法找到或执行的入口。 |
| MAN-04 | **写信与草稿**：新建合成邮件，输入收件人、主题、正文并添加小型自制附件；依次切换邮箱内设置、网盘及聊天工作区，再返回草稿；保存、重开并向另一测试账户发送。双方检查正文和附件。 | 切换时编辑内容及附件保留；保存后可恢复；发送和接收内容一致，不产生重复邮件。若保存报错，内容应保留、错误明确；不要连续重复发送。 |
| MAN-05 | **退出及账户隔离**：有未保存草稿时尝试关闭窗口或退出，按提示取消后确认内容；成功保存后退出，再用另一测试账户登录。结束时恢复原账户。 | 未保存内容不会无提示丢失；另一账户看不到第一账户的草稿或邮件。若无法安全构造保存失败，仅记录正常退出，故障分支记阻塞。 |
| MAN-06 | **窗口尺寸与焦点**：取消最大化，分别缩窄、拉宽窗口，打开待办详情，再关闭详情；也在最大化及还原后查看邮箱和待办。使用 Tab、Enter、Space 操作可聚焦控件。 | 不出现主要按钮、输入框或详情被裁切；窄窗口详情可返回列表，关闭后焦点可继续操作；邮箱不遮挡左侧导航或窗口操作。记录具体窗口尺寸及系统缩放比例。 |
| MAN-07 | **待办基本功能**：在桌面新建列表和任务，编辑标题、备注、截止日期、步骤；标重要、加入“我的一天”，完成并恢复；在 Web 刷新查看。 | 智能视图、详情和完成状态与操作一致；两端显示同一账户的数据。新建后网络或刷新报错时按提示操作，不盲目重复创建。 |
| MAN-08 | **分配与附件**：A 将仅含合成内容的任务分配给 B；B 在“分配给我”查看并完成任务或步骤。A 从网盘选择合成文件作为附件，验证有权限用户可打开；移除附件后检查网盘原文件仍存在。 | 共享前有确认说明，负责人只看到授权任务；附件访问遵循网盘权限，移除引用不删除原文件。结束后取消分配并删除本轮测试对象。 |
| MAN-09 | **提醒与重复**：创建数分钟后提醒的测试任务，在提醒到期前保持一端在线；查看提醒，并验证完成或取消后不再重复提醒。另建有截止时间的每日重复任务，完成一次后查看下一次。 | 到期后正常网络下约 60 秒内生成一次服务端提醒，重复检查不应出现多条；重复任务仅生成一个下一实例。系统通知取决于授权和设备状态，不将它等同于服务端提醒。 |
| MAN-10 | **本人及对方状态**：A 使用桌面和 Web 同时登录，B 观察 A；依次关闭 A 的一个连接及最后一个连接，重连后再交换角色。测试忙碌、离开、请勿打扰、隐身，结束恢复原状态。 | 任一连接仍有效时不应误显示离线；最后连接正常关闭及重连后，正常网络下目标 5 秒内收敛。本人连接状态与主动状态分开；隐身不向对方暴露在线。 |
| MAN-11 | **后台与网络恢复**：最小化桌面窗口数分钟再恢复；如有可隔离的测试网络，短暂断开并恢复，再观察本人及对方状态和消息。 | 后台不应频繁误判离线；恢复后可重新连接，状态最终一致。前台异常断网服务端过期目标不超过 90 秒；记录时间及网络条件，不能隔离时记阻塞。 |
| MAN-12 | **邮件通知点击**：在已授权通知的 Windows 设备上，由另一账户发送合成邮件，点击该测试通知；若可安全实现，再切换账户后点击先前通知。 | 当前账户的通知进入对应邮件；旧账户通知不能在新账户泄露或打开旧邮件。仅操作本轮通知。Windows 点击尚需实机验证；macOS、Linux 邮件通知点击尚未接入，不应记为已通过。 |
| MAN-13 | **手机与其他平台**：真实手机浏览器登录，检查消息、待办入口及基本操作；如有 macOS/Linux 桌面，检查邮箱窗口、草稿、窗口尺寸和账户切换。 | 各自单独记录设备、浏览器或应用版本、可操作性和问题；缺设备记阻塞，不将桌面浏览器缩小当作手机实测。 |
| MAN-14 | **常用回归**：双向发送合成私聊消息、上传并下载自制小文件，检查历史；仅在双方测试群测试群消息。 | 两端收到正确内容和文件；刷新或重启后历史仍正确。更完整的功能范围继续按 [测试用例](test-cases.md) 执行。 |

## 登录窗口外观回归

- 在 320 × 448 的桌面登录窗口检查手动登录、自动登录倒计时、登录中及网络错误状态；分别检查浅色和深色主题。
- 顶部 SMJ 原版反白标识应完整位于同一纯蓝底色内，J 不得被背景分界线穿过；窗口设置、最小化和关闭图标清晰可见。
- 输入账号、密码及两步验证码，展开历史账号并切换账号；输入框和登录按钮不得遮挡，内容超高时可滚动。
- 使用 Tab、Enter、Space 操作底部按钮；取消登录、移除账号及“更多”菜单仍可用，关闭扫码登录时“更多”居中。
- 此项只检查登录界面，不使用真实凭据截图；自动登录、取消登录及移除账号的实际效果须在授权的桌面测试账户上另行确认。
