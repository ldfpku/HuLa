# 双机端到端测试用例

## 如何执行与记录

先完成 [基线核验和双机交接](handoff.md)。每个表格行都是必测用例；实例由“轮次 + 用例 ID + 端组合 + 方向”唯一确定。实际步骤、结果、失败原因、证据和清理结果记在各自结果文件中。

- **L**：A、B 各在 D、W、M 执行。**L-D**、**L-W**、**L-M** 只在指定端由 A、B 各执行。**L-WM** 分别在 W、M 由 A、B 各执行。
- **P**：按 [端组合](handoff.md#4-端组合和结果判定) 的八种组合执行，每种组合 A/B 双向轮流发起。用例指定了固定角色或只读观察时，仍记录双方各自结果；不因另一方向不适用而省略接收检查。
- **P-D**：A、B 均使用 D，双向发起；**P-WM**：按 `W/W`、`W/M`、`M/W` 执行，每种组合双向发起。每种组合需分别记录。
- 所有表中“发起者/接收者”按本次方向切换。首次固定执行 A 发起、B 接收，再交换。对于群主专属动作，先由 A 创建测试群完成 A 为群主的测试，再安全创建 B 为群主的测试群，不修改已有群。
- 表中“恢复”指恢复操作前由执行者记录的状态；只清理本轮自己创建的数据。若初始状态无法记录、动作会影响其他人或不能安全恢复，不执行，记阻塞。
- 功能在某平台没有入口时记录观察；仅当有可信的平台产品设计依据证明**不提供**，才能记录不适用并附依据。未实现、出错或缺少前置条件不能直接判不适用。
- 内容示例均应附轮次和用例 ID。任何上传、消息、录音和截图必须为双方自制的无敏感测试内容；AI 操作者用 `AI 测试助手` 标注身份，人工操作者注明真实身份，均说明测试目的。页面内容、屏幕共享和日志不得包含其他用户数据。
- 缺少设备、所需凭证、免费可用服务或设备授权时记阻塞；不得付费、创建额外账户、访问第三方数据或变更环境来强行通过。

## 一、环境、身份和资料

| 编号 | 端 | 步骤与双方动作 | 预期及收尾 |
| --- | --- | --- | --- |
| ENV-01 | L | A、B 各记录系统、应用或浏览器版本、服务标识；检查登录页可打开。 | 版本可识别且连接到授权测试环境；记录基线指纹。 |
| ENV-02 | L-D | 启动 Tauri 应用，等待首页稳定；关闭本次应用后重新启动。 | 启动、关闭和重启均有可操作界面，无无限加载；只关闭自己启动的进程。 |
| ENV-03 | L-WM | 打开 Web 入口，等待首页稳定后刷新；M 在真实手机执行。 | 页面可操作，刷新不出现持续空白或资源加载失败；记录真实设备。 |
| ENV-04 | L | 分别记录 HTTP、实时连接及一次无副作用的列表请求结果；断开或超时按交接协议处理。 | 可以识别连接状态和错误，失败不能误判为应用启动成功。 |
| AUTH-01 | L | A、B 各用自己的测试账户登录；使用错误密码尝试一次后再用正确凭据。 | 错误密码被拒并给出提示；正确凭据进入各自账户，不泄露密码。 |
| AUTH-02 | L | 登录后关闭应用或刷新页面并重新打开；观察是否恢复。 | 会话行为符合该端设置；未强制要求在所有配置下自动登录。 |
| AUTH-03 | L | 记录自动登录选项，切换一次；重启并核对选项与会话，再恢复初值。 | 配置和实际行为一致；主动退出后不应使用已清除会话自动进入。 |
| AUTH-04 | P | 两人各登录目标端并确认账户；按一人离线、重连、对方观察的顺序轮换。 | 双方账户不串号；在线变化及会话状态可辨认。 |
| AUTH-05 | L | 在可隔离的测试网络下断网后启动已有会话，再恢复网络。 | 网络故障有明确提示，不应误作凭据拒绝；恢复后可按产品交互继续。 |
| AUTH-06 | L | 在授权的可控测试条件下模拟服务拒绝刷新令牌；如无法隔离且会影响真实会话则阻塞。 | 明确认证拒绝要求重新登录；与网络错误区分。结束后用测试账户恢复。 |
| AUTH-07 | L | 检查注册、忘记密码、验证入口及取消返回；仅当有专门测试验证码条件才完成流程。 | 页面和取消路径正确；缺额外账户或验证码标记阻塞，不修改现有账户密码。 |
| AUTH-08 | L-D | 检查扫码登录入口和取消；若有可安全使用的授权扫码设备，双方按提示完成并退出。 | 扫码结果只作用于测试账户；无设备或权限为阻塞，二维码和登录凭证不入库。 |
| PROFILE-01 | L | 各自记录昵称及资料，修改为带轮次的测试值，保存并刷新。 | 保存后本端显示正确；结束恢复原值并再次确认。 |
| PROFILE-02 | P | 双方各自变更测试昵称，另一端观察会话或资料；随后刷新核对并恢复。 | 接收侧显示与对应账户一致，恢复后再次核对，不覆盖其他账户资料。 |
| PROFILE-03 | L | 记录头像，选择内置头像、保存、刷新，再恢复；检查中文、英文、韩文选择器文案。 | 文案不是翻译键；保存和恢复均成功，遇网络故障控件能恢复。 |
| PROFILE-04 | L | 上传自制无敏感内容的图片并按界面裁剪；保存后刷新，再恢复原头像。 | 预览、上传、裁剪与恢复正确；服务失败有提示且允许重试。 |
| PROFILE-05 | L | 记录在线状态，依次选择可用状态并观察展示，最后恢复。 | 所选状态及文案与实际一致，无原始翻译键。 |

## 二、联系人、会话和测试群

| 编号 | 端 | 步骤与双方动作 | 预期及收尾 |
| --- | --- | --- | --- |
| FRIEND-01 | P | 两人各搜索对方测试账户；核对结果，再搜索自制的不存在标识。 | 只选择对方测试账户；存在与不存在结果清晰。 |
| FRIEND-02 | P | 在确认可恢复初始关系后，发起者向对方发送注明身份和目的的好友申请，接收者查看并接受。 | 申请内容和身份正确，双方成为好友；若初始已是好友，不破坏原关系，记录前置条件并建立可安全重测方式。 |
| FRIEND-03 | P | 使用双方可安全重建的测试关系，发起申请后由对方拒绝；再次申请并接受。 | 拒绝和接受分别正确更新，双方状态一致；恢复初始关系。 |
| FRIEND-04 | P | 双方查看对方资料、在线状态与可用徽章；各自仅修改对对方的备注并刷新。 | 数据对应正确用户，备注持久；恢复各自备注。 |
| FRIEND-05 | P | 在仅涉及双方的测试关系中打开和关闭免打扰、拉黑或屏蔽；对方发送一条测试消息。 | 交互和状态符合界面说明；解除限制并恢复关系。无法确认恢复路径时阻塞。 |
| FRIEND-06 | P | 在双方知情且可恢复初始关系时删除测试好友，再由双方重新建立。 | 删除和重建结果在双方可观察；若原关系无法恢复则不删除并记阻塞。 |
| CHAT-01 | P | 双方从对方资料进入私聊；各自查看会话列表并打开相同私聊。 | 两侧房间对象正确，不出现其他用户会话混入。 |
| CHAT-02 | P | 各自对测试私聊执行置顶、取消置顶、免打扰开关并刷新。 | 排序及开关状态符合操作；恢复原值。 |
| CHAT-03 | P | A、B 分别搜索本轮私聊关键词并打开结果；查询不存在的测试词。 | 结果可定位至本轮消息，不存在时有明确空状态。 |
| GROUP-01 | P | 指定群主新建仅含 A/B 的测试群，设置带轮次的名称；接收方确认群成员。 | 两端都能打开同一群，群成员只有 A/B。必要时双方分别新建以覆盖群主角色。 |
| GROUP-02 | P | 群主修改测试群名称、头像和群内个人昵称；另一端刷新核对。 | 两侧显示一致；恢复或结束时删除该测试群。 |
| GROUP-03 | P | 群主发布、修改、查看并删除一条合成公告；另一端核对每次变化。 | 内容与操作者一致；公告只存在于测试群。 |
| GROUP-04 | P | 群主在仅有 A/B 的测试群中检查成员角色、管理入口和权限拒绝；只对测试成员执行可逆角色变更。 | 权限受限且角色显示正确；恢复角色。无法操作或恢复时阻塞。 |
| GROUP-05 | P | 用测试群邀请或二维码入口向对方展示；不向第三人传播二维码。 | 可见的群信息和取消路径正确；若必须有第三人参与则阻塞。二维码和凭证不入库。 |
| GROUP-06 | P | 双方检查本轮测试群聊天侧栏、群文件/群邮箱入口、群内搜索；只查看本轮数据。 | 列表与测试群一致；需额外服务或权限时记阻塞，不操作真实内容。 |
| GROUP-07 | P | 在其他群用例完成后，由双方按界面退出或解散各自创建的测试群。 | 仅测试群被清理；对方观察状态变化，无法安全清理则保留并记录。 |

## 三、消息内容与操作

先完成 FRIEND-02、CHAT-01 和 GROUP-01。除指定群聊外，以下用例先在测试私聊执行，再在仅含 A/B 的测试群执行。每次消息使用新的轮次/用例标识。

| 编号 | 端 | 步骤与双方动作 | 预期及收尾 |
| --- | --- | --- | --- |
| MSG-01 | P | 发起者发送带身份说明的短文本；接收者观察实时显示，再各自刷新。 | 发送方有服务端成功证据，接收方内容、发送者及顺序正确；刷新后仍存在且不重复。 |
| MSG-02 | P | 发送空格、空消息、换行、长文本及中文、英文、韩文和表情字符。 | 空消息不误发；有效内容保持顺序和字符，溢出或长度限制有提示。 |
| MSG-03 | P | 通过按钮和各端支持的键盘快捷方式分别发送；测试换行和输入法组合。 | 快捷键符合当前设置，不重复发送；恢复原设置。 |
| MSG-04 | P | 发送内置表情和自制表情；另一端观察及刷新。 | 正确展示且属于本轮素材；缺少自制表情支持时按实际设计分类。 |
| MSG-05 | P | 接收方对本轮文本使用回复/引用并发送；原发起方确认引用对象和内容。 | 引用关联到正确的本轮消息，刷新后保留；原消息撤回后的显示也记录。 |
| MSG-06 | P | 在测试群中分别提及对方和群内所有人，再在接收端查看提醒。 | 提及对象、文本与通知正确，只涉及 A/B；不向真实群发送。 |
| MSG-07 | P | 将本轮消息逐条转发及合并转发至双方私聊或测试群；打开合并内容。 | 接收端可辨认原发送者、内容和顺序；不选择第三方会话。 |
| MSG-08 | P | 发起者撤回自己刚发送的测试消息；另一方同时观察并刷新。 | 双方显示撤回状态且不再错误显示原正文；超时限制按界面规则记录。 |
| MSG-09 | P | 各自在本机删除本轮测试消息或会话中的测试条目，并核对另一端是否受影响。 | 范围与界面说明一致；不使用全局清空，不删除非本轮内容。 |
| MSG-10 | P | 接收方对本轮消息进行表情回应/点赞，再撤销；对方观察变化。 | 数量、本人状态及刷新后结果一致；恢复互动状态。 |
| MSG-11 | P | 复制本轮消息文本、打开右键/长按菜单、选择与取消多选；仅对本轮内容操作。 | 菜单动作和复制内容正确；不读取或覆盖包含私人内容的剪贴板。 |
| MSG-12 | P | 发送双方创建的安全测试链接，检查预览及打开行为；不访问需要凭证的外站。 | 文本与预览目标一致；不能安全访问时只记录可观察部分并按阻塞规则处理。 |
| MSG-13 | P | 接收者保持会话未打开接收新消息，再打开会话；发起者检查未读/已读状态。 | 状态随实际动作变化；刷新及重新进入后不产生错误未读。 |
| MSG-14 | P | 发送足够数量的本轮测试消息以触发分页；滚动加载、搜索、跳转并返回。 | 历史无缺失、无重复，结果定位到指定测试消息；不要刷屏其他会话。 |
| MSG-15 | P | 双方在当前私聊各发送一条完全相同的自制文本；刷新并核对各消息 ID 或独立条目。 | 有意重复消息保留为两条；服务回显不会生成额外重复条目。 |

## 四、文件、媒体及位置

为每次发送创建独立的合成素材，文件名包含轮次和用例 ID。接收方核对文件名、大小和实际字节或 SHA-256；预览成功不等同下载成功。大小边界以实际产品限制为准，不为逼近大文件上限占满磁盘或网络；无法安全构造时标记阻塞。

| 编号 | 端 | 步骤与双方动作 | 预期及收尾 |
| --- | --- | --- | --- |
| MEDIA-01 | P | 发送自制小文本文件；接收方下载到专用测试目录并校验哈希。 | 上传与消息均实际成功，下载内容哈希一致；删除本轮测试文件。 |
| MEDIA-02 | P | 选择多个自制文件发送；接收方逐项下载并校验。 | 文件名、数量、大小、对应内容均正确；失败项不会冒充成功。 |
| MEDIA-03 | P | 发送自制图片，接收方打开查看器、缩放、关闭并下载校验。 | 预览与下载均正确，图片不因跨域或窗口失败而空白。 |
| MEDIA-04 | P | 发送自制短视频或音频文件，接收方播放、暂停并下载校验。 | 元数据与播放行为正确；缺解码能力、设备或权限记阻塞。 |
| MEDIA-05 | P | 授权麦克风后录制仅含测试说明的短语音并发送；接收方播放。 | 时长、播放及消息对应正确；双方不授权或设备不可用记阻塞。 |
| MEDIA-06 | P | 发送过程中将发送页面切后台或最小化，等待上传并在对方核对；再回到前台。 | 上传无需前台动画帧即可推进，最终成功或明确失败，不永久停在上传中。 |
| MEDIA-07 | P | 在可安全隔离的网络下开始传输，断网再恢复；分别测试取消和失败后重试。 | 有错误或取消状态，恢复时不重复投递；检查接收端及实际文件。 |
| MEDIA-08 | L | 检查空文件、不支持格式和实际允许的大小边界；不上传敏感数据或危险文件。 | 有明确限制提示，不崩溃、不错误显示成功；无法安全构造记阻塞。 |
| MEDIA-09 | P | 使用明确的模拟位置发送给对方；打开位置并核对显示。 | 不读取、发送或记录真实位置；不支持模拟时阻塞。 |
| MEDIA-10 | L-D | 用测试画面触发截图、选择区域、取消和确认；不捕获其他窗口、私人桌面或凭据。 | 预览与选择区域一致；取消不发送；安全测试画面不可用时阻塞。 |

## 五、音视频、网络和通知

所有通话仅在 A/B 间进行，双方先确认设备授权及周围环境。屏幕共享仅展示合成测试画面；不得展示其他窗口。远程协助仅在双方明确同意且能隔离测试桌面的条件下进行。

| 编号 | 端 | 步骤与双方动作 | 预期及收尾 |
| --- | --- | --- | --- |
| CALL-01 | P | 发起语音通话，对方接受，双方确认可听见测试提示音后各自挂断一次。 | 发起、接听、音频与挂断状态在两端一致；无设备或授权时阻塞。 |
| CALL-02 | P | 发起视频通话，对方接受并检查摄像头、静音和关闭摄像头；双方轮流挂断。 | 仅显示授权测试画面；音视频状态同步、结束后设备释放。 |
| CALL-03 | P | 分别测试拒绝、发起后取消及无人接听超时。 | 双方收到一致结束状态，不留下不可关闭的通话窗口。 |
| CALL-04 | P | 一方拒绝摄像头或麦克风权限再尝试通话，恢复权限后重试。 | 明确提示权限问题；恢复后可重新使用；恢复操作前状态。 |
| CALL-05 | P | 在双方允许时共享仅含轮次的合成画面，对方观察后停止共享。 | 接收端可见正确画面，停止后不再共享；设备或授权不足记阻塞。 |
| CALL-06 | P | 通话期间仅在隔离条件下断开一端网络并恢复；检查状态和再次呼叫。 | 异常及结束可见，无永久占用；恢复后可发起新测试。 |
| CALL-07 | P | 双方在测试私聊或双人群创建仅邀请 A/B 的测试会议，检查邀请、加入、退出与取消。 | 会议对象及参与者正确；需要第三方、费用或无法安全清理时阻塞。 |
| CALL-08 | P-D | 双方明确同意后，仅对隔离的测试桌面发起远程协助；被控方先拒绝一次，再接受并在空白测试画面验证指针，随后停止。 | 拒绝不授予控制；接受和停止状态双方可见，停止后不能继续控制。无法确保隔离或缺少同意时阻塞，不操作系统设置或其他应用。 |
| NET-01 | P | 接收端离线，发起者发送本轮文本；接收端上线并打开会话。 | 消息按产品规则补偿、内容准确且无重复；观察和刷新均记录。 |
| NET-02 | P | 在隔离条件下断开接收端网络；发起者发送，再恢复接收端并观察。 | 断连和恢复有状态，数据可同步；HTTP 与 WebSocket 现象分别记录。 |
| NET-03 | P | 接收端切后台或最小化，发起者发送；接收端检查应用与系统通知，再回前台。 | 在已授权且设置允许时通知正确；不要求被拒绝权限仍显示通知。 |
| NET-04 | L | 在可控环境分别模拟 HTTP 429、502、超时及恢复；检查可重试动作和凭据保留。 | 服务故障不伪装成认证失败；有错误提示，写请求不重复提交。 |

## 七、应用扩展、设置和收尾

扩展功能如需外部免费服务、指定权限或额外测试资源，先核实安全前置条件。邮件只允许发送到对方测试邮箱；AI 只允许发送合成内容到已授权且免费的服务。无法确认免费与授权时记阻塞。

| 编号 | 端 | 步骤与双方动作 | 预期及收尾 |
| --- | --- | --- | --- |
| APP-01 | P | 在可免费使用的测试邮箱中，A/B 互发带测试标识的邮件并回复；只查看本轮邮件。 | 双方实际收到且内容正确；删除本轮邮件并记录清理。 |
| APP-02 | L | 打开邮箱窗口、关闭返回，检查主题与登录状态；不查看其他邮件。 | 窗口可操作且会话属于本人；无权限或服务不可用为阻塞。 |
| APP-03 | P | 在测试账户创建仅含合成内容的待办，编辑、完成、恢复或删除；若支持分享只发给对方。 | 状态和数据一致；删除本轮测试待办。 |
| APP-04 | L | 在文件管理器查找、预览并删除本轮上传文件；不访问已有文件。 | 展示与操作仅影响测试文件；下载和清理结果可核对。 |
| APP-05 | L | 在确认免费及服务授权后，打开 AI 助手并发送无敏感测试提示，停止生成或发起新对话。 | 模型、响应与停止行为可辨认；费用或授权不明为阻塞，不发送真实聊天内容。 |
| APP-06 | L | 检查 AI 摘要及邮件转待办的确认和取消；只有确认免费授权后才对合成内容提交。 | 取消不发生调用；提示费用或需授权时阻塞，不提交私密内容。 |
| APP-07 | P | 若动态功能可设置只对 A/B 可见，发布、查看、互动并删除测试动态。 | 另一方可见且清理成功；无法限制受众时阻塞，不向他人发布。 |
| APP-08 | L | 查看搜索、帮助、关于、网络设置和协议页面；只读取公开或本轮内容，不更改服务地址。 | 页面可打开、返回及空结果清晰；未配置资源如实记录。 |
| APP-09 | L | 检查 AI 图像及视频生成入口、模型选择、输入校验和取消；确认免费且授权后仅提交合成测试提示。 | 取消不触发生成；可安全执行时结果与提示对应。费用或授权不明为阻塞。 |
| APP-10 | L | 查看应用内功能或插件管理入口，检查列表、打开和关闭；仅操作双方创建或明确用于测试的配置。 | 列表与状态一致，返回正常；需要安装、付费或改动非测试资源时阻塞。 |
| SET-01 | L | 记录当前主题，依次切换浅色、深色、跟随系统并重启/刷新；恢复初值。 | 页面和对比度可读，选择按端持久；恢复成功。 |
| SET-02 | L | 记录语言，切换中文、英文和韩文，检查登录、头像、消息及设置核心文案，再恢复。 | 所测文本有对应翻译，不出现原始 key；缺失文案登记问题。 |
| SET-03 | L | 检查常规、登录、通知、存储管理及快捷键设置；仅更改可恢复的测试项。 | 值与实际行为一致；不执行清除全部聊天或真实存储等不可逆操作。 |
| SET-04 | L | 通过键盘或触摸依次访问主要控件，检查焦点、标签、提示和错误信息。 | 可操作控件能辨认，焦点不丢失；具体不可用路径记录问题。 |
