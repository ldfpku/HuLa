### E2E-BUG-001：A 端 Web 开发代理请求超时

- 轮次、基线及发现时间：`E2E-20261029-01`，源码基线 `a1229ef3`，2026-10-29 14:53–15:07，UTC+08:00。
- 关联用例及执行者：A 的 ENV-03、ENV-04、AUTH-01，W 本地实例。
- 前置条件：本机启动 Web 开发服务器，目标为授权测试服务。
- 操作步骤：
  1. 打开本机 Web 登录页并观察会话和配置请求。
  2. 使用错误密码尝试一次登录。
  3. 对公开配置接口分别经本机开发代理和系统默认网络路径作只读检查。
- 预期结果：请求成功或明确返回服务、认证错误；错误密码应被明确拒绝。
- 实际结果：页面的会话、配置和登录请求超时；本机开发代理的只读配置请求在 12 秒客户端限时内未返回，而通过系统默认网络路径请求同一接口约 1.6 秒返回 HTTP 200。系统代理绕过后的目标接口请求在 10 秒内超时。启用 Node 的环境代理设置后，本机开发代理请求一次返回 200，随后浏览器及本机请求仍超时。不能据此推断登录、实时连接或所有服务接口正常。
- 复现次数及条件：页面请求在不同启动检查中出现超时；14:58 和 15:05–15:07 对不同网络路径进行了只读探测。B 端尚未核验。
- 影响范围、严重程度和优先级：阻碍本机 Web 登录及后续端到端测试；其他端和其他机器影响范围待确认，优先级待判定。
- 脱敏证据及双方确认：A 的浏览器错误提示及 HTTP 状态摘要；B 尚未确认。
- 可能原因与已验证事实：原因待定位；上述对比不证明故障位于某个特定组件。B 端也观察到超时及一次 502，但是否同因尚未确认。
- 临时处置或阻塞：同机测试中为 Web 开发代理临时显式配置本机已有 HTTPS 代理，随后 B 账户登录、双向消息和文件传输成功；该环境条件不等于修复了默认配置或服务问题。未修改产品代码。
- 修复版本、变更与自动化命令/结果：未修复。
